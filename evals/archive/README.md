# Archived eval runs

Saved runs of the evals from Jhola's first version, before it was rebuilt as one shopping agent:

- `builder-results/`: the 3-cart builder's eval (35 one-line requests, three carts each).
- `agent-results/`: the cart editor agent's eval (29 scripted edits of saved 3-cart sets).

The code that produced them is in the git history. The shopping agent's eval lives in `evals/chat/`; its 35 one-line requests are the same ones (`evals/queries.json`), now played as new chats.
